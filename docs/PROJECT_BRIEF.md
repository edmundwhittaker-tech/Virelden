# Project brief — 22 October 2026

Start with a basic Phaser + TypeScript environment for a top-down isometric game based on Virelden.

## This milestone

One simple stone courtyard. One placeholder character that walks with WASD or arrows.
The character stays within the floor and cannot pass through the four pillars. No other gameplay.
A fixed 2D ground projection creates the isometric appearance; this is not a 3D engine.

## Acceptance

A clean checkout installs reproducibly, passes movement/collision tests, type-checks and builds.
The browser loads without errors; keyboard movement, reset and focus cleanup work.
Inspect desktop and small viewport screenshots.
Provide beginner-friendly browser development instructions and report actual publishing status.

## Later

Have Edmund try the movement before deciding what to build next. No final art or expanded game systems during this milestone.
Placeholder art and the unnamed courtyard do not establish Virelden lore canon.
